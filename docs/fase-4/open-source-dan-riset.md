# 4.11 Open Source & Riset

:::info Detail modul
**Fase 4 — Expert** · **Estimasi:** 6 jam
:::

Cara tercepat naik level adalah membaca kode orang hebat dan berkontribusi. Modul ini membuka pintu itu.

## Tujuan pembelajaran

Setelah menyelesaikan modul ini, kamu mampu:

- Membaca source code library populer secara terarah.
- Membaca PEP dan mengikuti diskusi desain bahasa.
- Mengirim pull request yang layak diterima.

## Materi inti

### Membaca kode

- Mulai dari test dan dokumentasi
- Ikuti satu alur eksekusi
- Gunakan git blame dan history

### Standar

- PEP 8, 484, 621, 517
- Proses Python Enhancement Proposal
- Diskusi di mailing list dan GitHub

### Kontribusi

- Memilih issue pemula
- Menulis test dan changelog
- Etika review dan komunikasi

## Latihan terbimbing

1. Telusuri satu fitur di library populer dari dokumentasi sampai implementasi.
2. Perbaiki typo dokumentasi atau tambahkan test kecil di proyek OSS.

## Studi kasus: Pull request pertama

Kirim satu kontribusi nyata ke proyek open source, sekecil apa pun, dan lalui proses review sampai merged.

**Langkah pengerjaan**

1. Pilih proyek yang kamu pakai dan issue berlabel pemula.
2. Diskusikan pendekatan sebelum menulis kode.
3. Kirim PR dengan test dan deskripsi jelas.

:::note Deliverable
tautan PR yang merged atau review yang substantif.
:::

## Checklist

- [ ] Tidak takut membaca source code library.
- [ ] Tahu cara mengikuti diskusi desain bahasa.
- [ ] PR selalu menyertakan alasan dan test.
- [ ] Bisa menerima review tanpa mengambil pribadi.

:::tip Catatan belajar
Setelah selesai, tulis lima baris di `catatan.md`: apa yang dipelajari, bagian tersulit, dan satu hal yang masih belum jelas. Catatan ini yang membuat progresmu terlihat.
:::
