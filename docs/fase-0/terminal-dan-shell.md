# 0.2 Terminal & Shell

:::info Detail modul
**Fase 0 — Fondasi** · **Estimasi:** 2 jam
:::

Terminal adalah antarmuka utama developer. Di modul ini kamu berlatih navigasi folder, manipulasi file, dan membaca exit code.

## Tujuan pembelajaran

Setelah menyelesaikan modul ini, kamu mampu:

- Berpindah folder dan memeriksa isi direktori dengan percaya diri.
- Membuat, menyalin, memindahkan, dan menghapus file lewat terminal.
- Memahami exit code, pipe, dan redirect.

## Materi inti

### Navigasi

- pwd, cd, ls atau dir
- Path relatif vs absolut
- Karakter khusus dan spasi pada nama file

### Operasi file

- mkdir, cp, mv, rm
- Melihat isi file dengan cat, head, tail
- Mencari file dengan find atau glob

### Alur data

- Redirect output ke file
- Pipe antar perintah
- Exit code dan arti 0 vs bukan 0

## Latihan terbimbing

1. Buat struktur folder proyek Python lengkap hanya dengan terminal.
2. Cari semua file .py di folder latihan lalu hitung jumlahnya lewat pipe.

## Studi kasus: Membangun kerangka proyek dari nol

Kamu mendapat spesifikasi struktur folder proyek dan harus membuatnya tanpa membuka file explorer.

**Langkah pengerjaan**

1. Buat folder src, tests, docs, dan data.
2. Buat file kosong main.py, config.py, dan README.md.
3. Tampilkan struktur akhir dengan perintah tree atau alternatifnya.

:::note Deliverable
Screenshot atau output terminal berisi struktur folder yang diminta.
:::

## Checklist

- [ ] Tidak panik saat terminal menampilkan path panjang.
- [ ] Bisa menjelaskan arti exit code 1.
- [ ] Bisa memindahkan file tanpa GUI.
- [ ] Tahu beda rm dan rm -r serta risikonya.
