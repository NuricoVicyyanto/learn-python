# Belajar Python: dari Beginner ke Expert

Selamat datang. Kurikulum ini disusun sebagai perjalanan bertahap, bukan kumpulan tutorial acak. Setiap fase punya tujuan, modul, studi kasus, dan syarat kelulusan yang jelas.

:::info Status kurikulum
Ini adalah **kerangka pembelajaran**. Setiap modul sudah berisi tujuan, materi inti, latihan, studi kasus, dan checklist. Materi mendalam serta solusi latihan akan ditambahkan bertahap.
:::

## Untuk siapa

- Siswa atau mahasiswa yang ingin belajar Python dari nol.
- Pemula yang sudah pernah menonton tutorial tetapi belum pernah menyelesaikan proyek.
- Developer bahasa lain yang ingin menguasai Python secara benar.
- Guru atau mentor yang butuh struktur pembelajaran yang bisa dipakai di kelas.

## Hasil akhir yang diharapkan

Setelah menyelesaikan seluruh fase, kamu bisa:

1. Menulis program Python yang jelas, teruji, dan mudah dirawat.
2. Membangun layanan web lengkap dengan database, autentikasi, dan pipeline rilis otomatis.
3. Mendiagnosis masalah performa, memori, dan konkurensi berdasarkan pengukuran.
4. Menjelaskan keputusan teknis kepada tim maupun pemangku kepentingan.
5. Memiliki satu proyek portofolio yang layak dipresentasikan.

## Peta perjalanan

| Fase | Level | Fokus | Durasi | Karya akhir |
| --- | --- | --- | --- | --- |
| [Fase 0](/docs/fase-0/) | Fondasi | Alat kerja, terminal, Git, debugging | 1 minggu | `hello-env` |
| [Fase 1](/docs/fase-1/) | Beginner | Sintaks inti, fungsi, struktur data, file | 4–5 minggu | Expense Tracker CLI |
| [Fase 2](/docs/fase-2/) | Intermediate | OOP, testing, package, SQLite | 6–8 minggu | Inventory System |
| [Fase 3](/docs/fase-3/) | Advanced | Typing, async, API, database, CI/CD | 8–10 minggu | TaskFlow API |
| [Fase 4](/docs/fase-4/) | Expert | Internals, performa, arsitektur, keamanan | 10–12 minggu | Proyek expert + writeup |
| [Fase 5](/docs/fase-5/) | Spesialisasi | Pilih satu jalur karier | 6–10 minggu | Proyek portofolio |

Total estimasi: **600–900 jam** atau sekitar **9–12 bulan** bila belajar 15–20 jam per minggu.

## Cara memulai hari ini

1. Baca [Cara pakai kurikulum](/docs/panduan/cara-pakai).
2. Siapkan lingkungan kerja di [Fase 0](/docs/fase-0/).
3. Buat folder `learn-python` di komputer dan jadikan repository Git.
4. Kerjakan satu modul per sesi belajar. Jangan lompat ke fase berikutnya sebelum checklist modul terpenuhi.

:::tip Aturan emas
Satu modul, satu commit, satu catatan. Kecil, selesai, lalu lanjut.
:::

## Prinsip belajar yang dipakai di sini

- **Praktik mengalahkan tontonan.** Minimal 60 persen waktu dipakai menulis dan memperbaiki kode.
- **Satu konsep, satu studi kasus.** Setiap materi langsung dipakai.
- **Ukur, jangan menebak.** Berlaku untuk performa maupun pemahaman.
- **Selesaikan, baru sempurnakan.** Proyek setengah jadi tidak mengajarkan banyak hal.
