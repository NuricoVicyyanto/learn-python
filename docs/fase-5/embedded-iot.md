# Embedded & IoT

:::info Track spesialisasi
**Durasi:** 6 minggu · **Fase 5**
:::

Jalur untuk menghubungkan Python dengan perangkat fisik, sensor, dan sistem pesan.

**Stack utama**

`MicroPython` · `pyserial` · `MQTT` · `gpiozero`

## Yang dipelajari

### Perangkat

- MicroPython dan keterbatasannya
- GPIO dan sensor
- Serial communication
- Konsumsi daya

### Jaringan

- MQTT publish dan subscribe
- QoS dan reconnect
- Keamanan kredensial
- Buffering saat offline

### Sistem

- Gateway Python
- Penyimpanan time-series
- Dashboard realtime
- Update firmware

## Proyek portofolio

Sistem sensor yang mengirim data lewat MQTT ke gateway, tersimpan di database, dan tampil di dashboard realtime.

## Kriteria selesai

- Perangkat pulih otomatis setelah koneksi putus.
- Data tidak hilang saat jaringan bermasalah.
- Kredensial perangkat tidak hardcoded.

:::tip Bukti karya
Portofolio yang baik punya tiga hal: masalah nyata, keputusan teknis yang bisa dijelaskan, dan bukti bahwa karya itu berjalan. Rekam demo singkat dan tulis README yang jujur.
:::
