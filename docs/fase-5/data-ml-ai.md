# Data, ML & AI

:::info Track spesialisasi
**Durasi:** 8 minggu · **Fase 5**
:::

Jalur untuk analisis data, machine learning, dan sistem berbasis model. Fokus pada validasi, reproduksibilitas, dan komunikasi hasil.

**Stack utama**

`numpy` · `pandas` · `polars` · `matplotlib` · `scikit-learn` · `PyTorch`

## Yang dipelajari

### Analisis data

- Pembersihan dan eksplorasi dengan pandas atau polars
- Visualisasi yang jujur
- SQL untuk analis

### Machine learning

- Feature engineering
- Validasi silang
- Metrik dan confusion matrix
- Bias dan kebocoran data

### Produksi

- Serialisasi model
- Inference service
- Model card dan monitoring
- MLOps dasar

## Proyek portofolio

Prediksi churn end-to-end: data bersih, eksperimen, model, API inferensi, dashboard, dan model card.

## Kriteria selesai

- Bisa menjelaskan mengapa metrik tertentu dipilih.
- Model bisa dilatih ulang dari data mentah dengan satu perintah.
- Hasil disajikan dengan bahasa yang dipahami pemangku kepentingan.

:::tip Bukti karya
Portofolio yang baik punya tiga hal: masalah nyata, keputusan teknis yang bisa dijelaskan, dan bukti bahwa karya itu berjalan. Rekam demo singkat dan tulis README yang jujur.
:::
