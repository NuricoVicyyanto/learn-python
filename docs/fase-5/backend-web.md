# Backend & Web

:::info Track spesialisasi
**Durasi:** 8 minggu · **Fase 5**
:::

Jalur untuk membangun layanan yang dipakai banyak pengguna. Fokus pada keandalan, keamanan, dan operasi.

**Stack utama**

`FastAPI` · `Django` · `PostgreSQL` · `Redis` · `Docker` · `Kubernetes`

## Yang dipelajari

### Aplikasi

- Autentikasi dan otorisasi
- Multi-tenancy
- Background job
- Caching dengan Redis

### Data

- Desain skema
- Migrasi tanpa downtime
- Indexing dan query tuning
- Backup dan pemulihan

### Operasi

- Docker dan Kubernetes dasar
- Observability
- Blue-green deploy
- Incident response

## Proyek portofolio

Aplikasi SaaS kecil multi-tenant dengan billing tiruan, job latar belakang, dan dashboard admin.

## Kriteria selesai

- Bisa menjelaskan alur request dari browser sampai database.
- Punya rencana scaling dan pemulihan bencana.
- Tidak menyimpan rahasia di kode.

:::tip Bukti karya
Portofolio yang baik punya tiga hal: masalah nyata, keputusan teknis yang bisa dijelaskan, dan bukti bahwa karya itu berjalan. Rekam demo singkat dan tulis README yang jujur.
:::
