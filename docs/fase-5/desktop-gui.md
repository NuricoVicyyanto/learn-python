# Desktop & GUI

:::info Track spesialisasi
**Durasi:** 6 minggu · **Fase 5**
:::

Jalur untuk aplikasi desktop yang dipakai sehari-hari. Fokus pada pengalaman pengguna dan pengemasan.

**Stack utama**

`PySide6` · `Tkinter` · `threading` · `PyInstaller`

## Yang dipelajari

### UI

- Layout dan widget
- Model-view
- Validasi input
- Aksesibilitas

### Concurrency

- Membuat UI tetap responsif
- Worker thread
- Progress dan pembatalan
- Sinkronisasi state

### Distribusi

- PyInstaller
- Installer dan update
- Penanganan crash
- Ukuran aplikasi

## Proyek portofolio

Aplikasi desktop dengan database lokal, ekspor laporan, installer, dan mekanisme update.

## Kriteria selesai

- UI tidak membeku saat operasi berat berjalan.
- Aplikasi bisa dipasang di mesin tanpa Python.
- Crash tercatat dan bisa didiagnosis.

:::tip Bukti karya
Portofolio yang baik punya tiga hal: masalah nyata, keputusan teknis yang bisa dijelaskan, dan bukti bahwa karya itu berjalan. Rekam demo singkat dan tulis README yang jujur.
:::
